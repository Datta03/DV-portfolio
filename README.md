# Dattatreya Vaidya — QA Portfolio

Static portfolio recreated from the screenshots, using HTML, CSS and vanilla JavaScript. Includes the cyan scroll progress bar, sticky navigation, animated skills ticker, responsive layouts, timeline, project cards, certificate links, contact cards and downloadable resume.

## Preview
Open `index.html` in a browser.

## Deploy on Vercel
1. Create a GitHub repository and upload the files/folders in this project.
2. In Vercel, choose **Add New → Project**, import the GitHub repository, and deploy.
3. This is a static site; it has no build step and no server-side dependencies.

## Review before publishing
- Check the experience dates and all content against the current resume.
- The resume download currently serves the uploaded DOCX file. If you prefer a PDF, replace the file and update both resume links in `index.html`.
- Verify that your phone/email are intended for public display.
- The Google AI and IBM BA certificate links point to the supplied Coursera share URLs.
- Replace the portrait with a different crop/original if desired.
